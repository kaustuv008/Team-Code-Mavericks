About PlacePilot & Team Code Mavericks

PlacePilot was built by Team Code Mavericks to solve the widespread problem of Revision Neglect and Preparation Bias among candidates preparing for technical campus recruitment.

The Problem We Solve

Most candidates instinctively over-practice topics where they already score well, avoiding difficult or unpracticed domains. When corporate placement drives occur, candidates are eliminated not because they didn't study, but because untested blind spots and stale memory decay were neglected.

The Decision Engine Algorithm

  • Untested Syllabus Protection: Any syllabus topic with 0 attempts automatically receives top High Priority. Untested domains are the highest risk in placement drives.
  • Mathematical Decoupling: Accuracy is evaluated strictly as $(Correct \div Tried) \times 100$. If 0 questions were attempted, it shows "Not practised yet".
  • Memory Decay Penalty: Topics unrevised for over 14 days decay in priority rank, protecting candidates from the Ebbinghaus forgetting curve.
